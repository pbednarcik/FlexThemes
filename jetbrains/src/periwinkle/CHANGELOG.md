# Changelog: Periwinkle Islands

## 0.7.0

- First public release: a light theme that pairs the soft periwinkle chrome of the classic Visual Studio Blue theme with deep purple accents: purple-tinted focused tabs, purple selection text and purple keywords.
- A calm editor palette in clearly separated colours: violet keywords, blue types, amber methods, red strings and green comments, with names in plain text, as in Visual Studio.
- Shared language colours for C#, Java, Kotlin, Go and Python, checked against the installed IDEs' own declarations.
- Every text colour is checked for contrast when the theme is built.
- Requires JetBrains IDEs 2026.2 or later with the Islands (new) UI. Tested in Rider, IntelliJ IDEA, GoLand and PyCharm 2026.2.3 on Windows.
