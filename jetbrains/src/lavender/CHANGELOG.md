# Changelog: Lavender Mist

## 0.7.1

- No theme changes; version aligned with the FlexThemes bundle.

## 0.7.0

- First public release: a light theme family with a soft lavender frame, cool white panels and deep purple accents, inspired by the classic Visual Studio Blue theme. Gold has Blue's gold active tab, Indigo a lavender selected tab with purple text and outline, Blue the periwinkle selection.
- Two editor schemes: Lavender Mist, with Visual Studio blue keywords, teal types, amber methods, red strings and green comments, and Lavender Mist Purple, with violet keywords and blue types.
- Shared language colours for C#, Java, Kotlin, Go and Python, checked against the installed IDEs' own declarations.
- Every text colour is checked for contrast when the theme is built.
- Requires JetBrains IDEs 2026.2 or later with the Islands (new) UI. Tested in Rider, IntelliJ IDEA, GoLand and PyCharm 2026.2.3 on Windows.
