# Changelog: FlexThemes

## 0.7.0

- First public release: one plugin with all nine appearances (Morning Mist, Lavender Mist Gold, Indigo and Blue, Blue Mist, Periwinkle Islands, Graphite, Periwinkle Night and Abyss) and eight editor schemes, including the alternative Lavender Mist Purple scheme.
- Contains exactly the themes and schemes of the standalone plugins; uninstall those before installing the bundle.
- Shared language colours for C#, Java, Kotlin, Go and Python, checked against the installed IDEs' own declarations.
- Every text colour is checked for contrast when the bundle is built, and every appearance is checked in native screenshots of all four IDEs.
- Requires JetBrains IDEs 2026.2 or later with the Islands (new) UI. Tested in Rider, IntelliJ IDEA, GoLand and PyCharm 2026.2.3 on Windows.
