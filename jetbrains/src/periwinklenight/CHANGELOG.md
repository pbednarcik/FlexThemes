# Changelog: Periwinkle Night

## 0.7.0

- First public release: the dark sibling of Periwinkle Islands, with deep indigo chrome, clearly separated panels and soft white text.
- A calm editor palette in clearly separated pastels: lilac keywords, cyan types, gold methods, peach strings and green comments, with names in plain text. Code colours reach at least APCA Lc 60, with comments and Code Vision hints deliberately quieter.
- Shared language colours for C#, Java, Kotlin, Go and Python, checked against the installed IDEs' own declarations.
- Every text colour is checked for contrast when the theme is built.
- Requires JetBrains IDEs 2026.2 or later with the Islands (new) UI. Tested in Rider, IntelliJ IDEA, GoLand and PyCharm 2026.2.3 on Windows.
