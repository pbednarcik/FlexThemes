# Changelog: Abyss

## 0.7.0

- First public release: a deep ocean dark theme with blue-green chrome and code colours like glowing sea life: coral keywords, mint types, gold methods, sky-blue strings, italic sage comments and names in plain text.
- Soft off-white text, no neon; code colours reach at least APCA Lc 60, with comments and Code Vision hints deliberately quieter.
- Shared language colours for C#, Java, Kotlin, Go and Python, checked against the installed IDEs' own declarations.
- Every text colour is checked for contrast when the theme is built.
- Requires JetBrains IDEs 2026.2 or later with the Islands (new) UI. Tested in Rider, IntelliJ IDEA, GoLand and PyCharm 2026.2.3 on Windows.
